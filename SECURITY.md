# Security policy

Only the latest release is supported. Security fixes go into the newest release, so
upgrade to it to receive them.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through
GitHub: go to the repository's **Security** tab and click **Report a vulnerability**.
Only the maintainers can see the report.

Include the HSDS version, how it's deployed (Docker, Kubernetes, or the `hsds`
launcher), and the steps or requests that show the problem.

If you can't use GitHub, email mlarson@hdfgroup.org.

We'll confirm we've received the report and investigate. If it's a real vulnerability,
we'll work on a fix and, where appropriate, publish a GitHub security advisory.
